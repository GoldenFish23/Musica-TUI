# For Contribution
The file itself represents the project structure essential to understand the project and make any ammendment.

## Project Structure: 
<i>*Every file for managing / creating app is inside build folder.</i>
1. <b>installer.py</b> - Python file that commands to install all necessary packages to run the app, the packages/modules are mentioned in packages.txt
2. <b>UI.py</b> - Only Logo designed in ASCII.
3. <b>themes.py</b> - List of Theme for the project.
4. <b>player.py</b> - Simple logics for managing audio streaming.
5. <b>musica.py</b> - The core logic that handles the project like streaming audio, visual effects, menu & settings.
6. <b>settings.json</b> - Settings in format `key:value` to load settings automatically.
